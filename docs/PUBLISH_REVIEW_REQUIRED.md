fully disclosed:

- Security blockers (auth-before-release, nonce-reuse on reset), missing
  replay/SA lifecycle/key zeroization.

- Routed timing not met; no post-synth security verification.
- `CLEAN_REBUILD_NOT_YET_PROVEN`; Corundum baseline unknown (see P1).
