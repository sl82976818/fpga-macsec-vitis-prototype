# Provenance

This document maps the source tree to its origins. It is the reference for
the "who wrote / who modified / what was generated" separation that is the
primary value of this release.

## The six-way separation

| Category | Meaning | Where in this release |
| --- | --- | --- |
| **LE SUN ORIGINAL** | Authored by Le Sun for this project | `src/macsec/`, `tb/security_regressions/`, `tb/cocotb/xpm_*_sim.v`, `tb/cocotb/hls_*_model.v`, `tb/tb_fpga_core_integration.v`, `scripts/`, engineering log, audits |
| **CORUNDUM MODIFIED** | Corundum files Le Sun modified (marked + patch) | `src/fpga/fpga_core.v`, `src/fpga/fpga_k35.v`, `constraints/fpga_k35.xdc`, `tb/cocotb/test_fpga_core_macsec_sfp.py` |
| **CORUNDUM UPSTREAM** | Unmodified Corundum/board files | `src/fpga/common/`, `src/fpga/lib/*`, `src/fpga/sync_signal.v`, `src/fpga/board_K35/`, `constraints/boot.xdc`, `constraints/corundum_syn/*.tcl`, `tb/cocotb/mqnic.py` |
| **AMD/VITIS UPSTREAM** | Unmodified Vitis example/HLS sources | `hls/src/project/aes128{enc,dec}/{test.cpp,test.hpp,main.cpp,Makefile,run_hls.tcl,description.json,gld.dat}` |
| **TOOL GENERATED** | AMD/Vivado/Vitis generated content | **Not included** (see `release_metadata/FILES_EXCLUDED.md`) |
| **NOT INCLUDED** | Unknown-provenance / vendor / build artifacts | See `release_metadata/FILES_EXCLUDED.md`, `docs/PUBLISH_REVIEW_REQUIRED.md` |

## Upstream baselines

- **Corundum**: bundled subset derived from the Corundum `fpga/` tree.
  Exact baseline commit: **`UPSTREAM_BASELINE_UNKNOWN`** (see `docs/BUILD.md`).
- **Vitis Libraries**: 2022.1 (`security/L1/tests/gcm/aes128{enc,dec}`),
  verified byte-identical.
- **HLS IP**: generated by Vitis HLS 2022.1 from those sources, part
  `xcku040-ffva1156-2-e`; generated RTL **not redistributed**.

## Unknown provenance (not published)

Files whose provenance could not be confirmed are **excluded** from the
release and enumerated in `docs/PUBLISH_REVIEW_REQUIRED.md` and
`release_metadata/FILES_EXCLUDED.md`. Nothing is published "because the
project needs it".
