# tb/cocotb — integration testbench

cocotb-based integration testbench for the MACsec-protected `fpga_core`.

## Files

| File | Provenance |
| --- | --- |
| `test_fpga_core_macsec_sfp.py` | Corundum test framework modified by Le Sun for MACsec (BSD-2-Clause-Views header retained + modification note) |
| `mqnic.py` | Corundum (unmodified) |
| `xpm_fifo_sync_sim.v`, `xpm_fifo_async_sim.v` | Le Sun behavioral sim models for XPM FIFOs (BSD-2-Clause) |
| `hls_aes128gcm_enc_model.v`, `hls_aes128gcm_dec_model.v` | Le Sun interface models for the HLS IP (BSD-2-Clause) |

## History and trust level

- The historical regression was **flaky**: 44 PASS / 23 FAIL across saved
  runs, with PASS and FAIL on the same day for the same DUT+TB.
- The checks are **loopback self-consistency only** (frame counts, payload
  echo) — **not** an independent oracle.
- Therefore **do not treat a green run of this testbench as security
  evidence**. See `docs/VERIFICATION_STATUS.md`.

## Requirements

- Python 3, cocotb 1.7.2, cocotb-test 0.2.4, cocotbext-axi 0.1.24,
  cocotbext-eth 0.1.22, cocotbext-pcie 0.2.14, scapy.
- The HLS IP simulation RTL (`test_*` modules) must be generated by the HLS
  build and placed where the TB expects (see `docs/BUILD.md`); the model
  wrappers in this directory bridge the interface.

## Running

Historical runner (root `scripts/test.sh`) invoked:

```
pytest -s -q tb/cocotb/test_fpga_core_macsec_sfp.py
```

A deterministic, production-parameter run is **not yet proven** — treat any
run as diagnostic, not a gate.
