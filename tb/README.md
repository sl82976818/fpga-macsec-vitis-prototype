# tb/

Verification assets.

| Directory | Contents |
| --- | --- |
| `tb_fpga_core_integration.v` | xsim project-mode integration testbench (plaintext frame sweep 64–1520 B, negative replay/tamper observations). Original Le Sun testbench |
| `cocotb/` | cocotb-based integration testbench (`test_fpga_core_macsec_sfp.py`, `mqnic.py`, XPM behavioral sim models, HLS IP interface models) |
| `security_regressions/` | independent E1/E2 behavioral security experiments (iverilog), see README |

## Verification honesty

The integration testbench historically had **flaky** results (44 PASS /
23 FAIL across runs, same-day PASS+FAIL) and only checks loopback
self-consistency — it is **not** an independent oracle. See
`docs/VERIFICATION_STATUS.md`. The E1/E2 experiments in
`tb/security_regressions/` are the strongest reproducible security evidence.

## Requirements

- cocotb 1.7.2, cocotb-test, cocotbext-axi/eth/pcie, scapy (see
  `tb/cocotb/README.md`).
- Icarus Verilog (iverilog) for `security_regressions/`.
- The HLS IP simulation RTL (module names `test_*`) is generated by the HLS
  build and is **not** redistributed; the interface model wrappers
  (`hls_aes128gcm_enc_model.v` / `dec_model.v`) are included.
